# MORI 单店电商系统

独立、可运行的电商项目。源码和商品图片就在此目录，不是低代码平台任务 JSON 中的片段；无需运行原 Web/API 或本地大模型。

## 打开系统

- 商城：http://127.0.0.1:54930/#/
- 我的订单：http://127.0.0.1:54930/#/orders
- 商家后台：http://127.0.0.1:54930/#/admin

| 用途 | 邮箱 | 密码 |
| --- | --- | --- |
| 顾客 | buyer@mori.local | Shopper123! |
| 商家 | admin@mori.local | Admin123! |

以上为本机演示账号，不是生产凭据。也可以通过页面注册独立顾客。切换角色请先点右上角账户退出，再登录另一个账号；顾客不能使用商家 API。

**支付、退款和物流都是演示业务流程，不会真实扣款、退款或发送包裹。** 不收集银行卡信息，不要输入真实敏感信息。项目目前只绑定本机，禁止直接开放到公网。

## 已实现

- 8 件带本地实图的商品；分类、关键词搜索、价格排序和商品详情。
- 访客购物车保存在浏览器，账号购物车保存在 SQLite；登录时合并，支持改数量、移除和缺货提示。
- 顾客注册、登录、退出；密码 bcrypt 哈希，HttpOnly/SameSite 会话 Cookie，登录轮换会话。
- 收货信息、订单备注、服务端计价；满 299 元包邮，否则运费 12 元。金额以整数分保存。
- 幂等下单、库存事务、缺货整单回滚；取消订单恢复库存，重复操作不能重复恢复。
- 我的订单、状态筛选、收货信息和物流展示；待付款、待发货、待收货、完成、取消、退款审核和已退款。
- 明确标注的演示付款；顾客申请未发货订单退款，商家批准或拒绝。
- 商家经营概览、成交额/订单/待发货/在售数量、最近订单和低库存提醒。
- 商品新增、编辑价格和库存、上下架；乐观版本控制，避免编辑覆盖其他订单造成的库存变化。
- 后台订单查询、筛选、详情、填写物流单号发货和退款审核。
- 桌面和手机布局、表格内横向滚动；Lucide 图标、表单错误、空状态和防重复提交。
- 严格输入校验、服务端角色和订单归属校验、CSRF、同源限制、请求限流、CSP。

## 本机运行

要求 Node.js **22.15 或更高版本**，使用内置 `node:sqlite`。在当前 Node 22 上会出现 SQLite 实验 API 提示；不是运行失败。本项目未引入额外数据库服务或原生编译依赖。

```powershell
Set-Location G:/github/games/projects/commerce
npm.cmd ci --ignore-scripts --no-fund --no-audit
npm.cmd start
```

默认端口 54930。如果被其他程序占用，设置不同端口，不要终止其他服务：

```powershell
$env:PORT='54931'
npm.cmd start
```

源码无需构建即可运行。完整停止并重启进程后，商品、顾客、会话、账号购物车和订单仍保留。

| [server.cjs](server.cjs) | Express HTTP 服务、鉴权、校验与路由 |

| [public/images](public/images) | 8 张本地商品图片 |

| [tests/store.test.cjs](tests/store.test.cjs) | 数据、事务和持久化测试 |

默认数据库：项目目录下 `data/commerce.sqlite`，包括 SQLite WAL/SHM 文件。此目录被忽略，不应提交顾客或订单数据。备份应先停止服务，或者使用正确的 SQLite 在线备份方式，不要仅复制正在写入的主文件。

环境变量 `MORI_DATABASE` 可指定其他数据库文件；默认示例商品只在新库中创建。`MORI_DEMO_ACCOUNTS=false` 只停止创建演示账号，**不会删除已有演示账号，也不会自动把系统变成生产配置**。

访客购物车在 localStorage，账号数据在数据库。更换浏览器不会迁移访客购物车，但同一账号登录后可以看到数据库中的购物车与订单。

## 边界

这是有实际交易闭环的单店本机第一版，不宣称生产级或覆盖全部电商业务。尚未接入真实支付/退款/物流、短信/邮件验证、找回密码、多规格 SKU、优惠券、会员、发票税务、已发货退货、自动超时关单及库存释放、多店和大规模并发部署。订单列表目前返回最近 200 笔，不是完整分页系统。

没有真实商户资质、价格/商品合规审核、隐私条款、完整审计与财务对账。商品图来自 [Unsplash](https://unsplash.com)，为本机样例素材，不代表有实物库存；公开商用前需核对商品与图片授权、品牌及真实描述。

会话 Cookie 适配本机 HTTP，不启用 Secure；公网部署必须改为 HTTPS、安全 Cookie、正式账号与授权策略、秘密管理、审计、备份、合规条款及支付回调验签。当前仅校验本机 Host 和同源，不提供生产网络边界保证；不能直接通过反向代理暴露演示账号。

页面字体优先使用 Google Fonts，断网时回退字体；商品图片、业务脚本、图标和数据均在本机。
